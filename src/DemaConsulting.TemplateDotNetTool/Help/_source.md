{{tool}} is the DEMA Consulting template for .NET command-line tools. It shows the standard options,
self-validation for regulated projects, and this built-in help.

Every operation is an option. The only command is `{{tool}} help`, which must be the first argument and takes
topic names, such as `{{tool}} help command-line`.
